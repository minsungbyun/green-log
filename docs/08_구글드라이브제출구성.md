## 01_서비스_접속링크.txt 본문 템플릿
```
서비스명: AI 식물관찰일지
접속 URL: https://ai-plant-journal.onrender.com
주제: 일상생활

주요 기능:
1. 식물 등록
2. 관찰일지 작성
3. 사진 및 메모 기록
4. AI 관찰 요약 생성
5. 식물 관리 조언 생성
6. 관찰 기록 조회/수정/삭제
7. 기록 내보내기 (CSV/JSON)
8. MCP 기반 확장 구조 제안

사용 방법:
1. 사이트에 접속한다.
2. "식물 등록" 화면에서 식물명을 등록한다.
3. "관찰일지 작성" 화면에서 식물과 상태를 입력한다.
4. "AI 요약/조언 생성" 버튼을 눌러 결과를 확인한다.
5. "저장" 버튼을 눌러 기록을 보관한다.
6. "기록 보기" 화면에서 과거 관찰 기록을 확인한다.

기술 구성:
- Node.js / Express
- Vanilla HTML / CSS / JS
- 데이터 저장: data/journal.json
- AI 모드: 기본 규칙 기반 (무료) / API Key 설정 시 Anthropic Claude API
- MCP 확장 구조: 동일 비즈니스 로직 공유 (lib/tools.js)

주의:
- Render 무료 플랜 특성상 첫 접속 시 30~60초 콜드 스타트가 발생할 수 있습니다.
- 무료 인스턴스 디스크는 영구 보장이 아니므로, 데모 데이터는 시간이 지나면 초기화될 수 있습니다.
- 위 한계를 보완하기 위해 시연영상을 함께 첨부했습니다.
```

## 04_소스코드.zip 구성
포함:
- `server.js`, `package.json`, `render.yaml`, `.env.example`, `.gitignore`
- `lib/`, `public/`, `mcp-server/`, `docs/`
- `README.md`

제외:
- `node_modules/` (npm install 로 복원)
- `data/journal.json` (실제 사용 중 누적된 데이터)
- `public/uploads/*` 의 실제 사진들 (개인정보 가능성)
- `.env` (있다면)

PowerShell 명령 예:
```powershell
Compress-Archive -Path server.js, package.json, render.yaml, .env.example, .gitignore, lib, public, mcp-server, docs, README.md -DestinationPath 04_소스코드.zip -Force
```

## 시연영상 구성안 (3~5분)
1. **인트로 (15초)** — 서비스명, 한 줄 소개
2. **메인 화면 둘러보기 (20초)** — Hero, 최근 기록, 네비
3. **식물 등록 (30초)** — 바질 등록
4. **관찰일지 작성 + AI 생성 (90초)** — 상태 입력, 사진 업로드, AI 요약/조언 생성 결과
5. **목록 / 수정 / 삭제 (45초)** — 카드, 모달 수정, 필터 검색
6. **CSV 내보내기 (15초)**
7. **통계 화면 (20초)**
8. **MCP 화면 + /api/mcp/tools (30초)** — 확장 구조 강조
9. **마무리 (10초)** — Render URL, 구글 드라이브 안내

- 권한: **뷰어**
- 경진대회 제출 URL 입력란에는 **이 폴더 공유 링크** 를 제출
