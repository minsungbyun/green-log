# AI 식물관찰일지 — 사용설명서

## 1. 서비스 소개
**AI 식물관찰일지** 는 사용자가 식물의 잎/흙/햇빛/물주기/키 등을 기록하면, AI 가 관찰 요약문과 관리 조언을 자동으로 생성해 주는 웹서비스입니다.

## 2. 접속 방법
1. 브라우저(PC 또는 모바일)를 엽니다.
2. 주소창에 다음 URL 을 입력합니다.
   ```
   https://ai-plant-journal.onrender.com
   ```
3. 회원가입 없이 바로 사용할 수 있습니다.

> 무료 인스턴스 특성상 첫 접속 시 30~60초 동안 화면이 늦게 뜰 수 있습니다.

## 3. 기본 사용 순서

### 1) 식물 등록
1. 상단 메뉴에서 **"식물 등록"** 을 클릭합니다.
2. "식물명" 을 입력합니다 (필수). 종류/장소/시작일/메모는 선택입니다.
3. **등록** 버튼을 누릅니다.

### 2) 관찰일지 작성
1. 상단 메뉴에서 **"관찰일지 작성"** 을 클릭합니다.
2. "식물 선택" 에서 등록한 식물을 고릅니다.
3. 관찰일자(기본: 오늘), 잎/흙/햇빛 상태, 물주기 여부, 키, 사진, 메모를 입력합니다.
4. **"AI 요약/조언 생성"** 을 누르면 화면 아래에 미리보기가 나타납니다.
5. **"저장"** 을 누르면 기록이 보관되고 목록 화면으로 이동합니다.

### 3) 기록 보기 / 수정 / 삭제
1. 상단 메뉴에서 **"기록 보기"** 를 클릭합니다.
2. 카드 단위로 기록이 보입니다.
3. 식물명 / 기간 / 키워드로 필터링할 수 있습니다.
4. 각 카드의 **수정** 버튼으로 내용을 고치고, **삭제** 버튼으로 지울 수 있습니다.

### 4) 내보내기
1. **"기록 보기"** 화면에서 **CSV 내보내기** 또는 **JSON 내보내기** 를 누릅니다.
2. 현재 필터 조건이 그대로 적용된 파일이 다운로드됩니다.

### 5) 통계 보기
- 상단 메뉴에서 **"통계"** 를 클릭하면 식물별 관찰 횟수, 최근 물주기, 최근 키, 관리 필요 식물을 한눈에 확인할 수 있습니다.

### 6) MCP 확장 구조 보기
- 상단 메뉴에서 **"MCP"** 를 클릭하면, AI 에이전트와 연결되는 4개의 Tool 명세와 향후 확장 방향을 확인할 수 있습니다.
- `https://<URL>/api/mcp/tools` 로 직접 메타정보 JSON 도 볼 수 있습니다.

## 4. AI 모드
- **기본**: 규칙 기반 요약/조언 (무료, 즉시 생성)
- **선택**: 서버 환경변수 `GOOGLE_API_KEY` 가 설정되어 있으면 자동으로 Google Gemini API 호출로 전환됩니다 (사진 분석·메모/요약/조언 생성).
- 어떤 경우에도 API Key 는 **서버 환경변수로만 사용**되며 브라우저에는 노출되지 않습니다.

## 5. 자주 묻는 질문
**Q. 데이터는 어디에 저장되나요?**
A. 서버의 `data/journal.json` 파일에 저장됩니다. Render 무료 플랜 특성상 재시작 시 초기화될 수 있습니다.

**Q. 회원가입이 필요한가요?**
A. 아니요. 이번 MVP는 단일 사용자 데모 용도이며, 인증 없이 누구나 이용할 수 있습니다.

**Q. 사진은 어디에 저장되나요?**
A. 서버의 `public/uploads/` 폴더에 저장되며 URL 은 `/uploads/파일명` 형태입니다.

**Q. AI 결과가 늘 같은가요?**
A. 규칙 기반 모드에서는 입력값이 같으면 결과가 동일합니다. AI API 모드에서는 모델 응답에 따라 매번 달라질 수 있습니다.
