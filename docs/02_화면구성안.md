# 02. 화면 구성안

총 6개 페이지로 구성한다. 모든 페이지는 상단 공통 네비게이션을 공유한다.

## 공통 네비게이션
홈 · 식물 등록 · 관찰일지 작성 · 기록 보기 · 통계 · MCP

## 1) 메인 화면 (`/`, `public/index.html`)
- 서비스 인트로 (Hero 영역)
- 주요 CTA: "오늘의 관찰 작성하기" / "식물 먼저 등록"
- 최근 관찰 기록 5건 카드
- AI 식물 관리 도우미 소개 카드

## 2) 식물 등록 화면 (`/plants.html`)
- 새 식물 추가 폼: 식물명(필수), 식물 종류, 키우는 장소, 키우기 시작일, 메모
- 등록된 식물 목록: 카드형 + 수정/삭제 버튼

## 3) 관찰일지 작성 화면 (`/journal.html`)
- 식물 선택 (드롭다운, 식물 등록과 연결)
- 관찰일자 (기본: 오늘)
- 잎 상태 / 흙 상태 / 햇빛 상태 / 물주기 (드롭다운)
- 키 (숫자), 사진 업로드, 자유 메모
- **AI 요약/조언 생성** 버튼 → 결과 미리보기
- 저장 버튼 → 목록으로 이동

## 4) 관찰일지 목록 화면 (`/list.html`)
- 필터바: 식물명, 시작일, 종료일, 키워드
- CSV / JSON 내보내기 버튼
- 카드형 목록: 대표 사진, 식물명, 관찰일자, 상태 태그, AI 요약
- 카드 액션: 수정(모달) / 삭제

## 5) 통계 / 요약 화면 (`/stats.html`)
- 등록된 식물 수, 관찰일지 수, 관리 필요 식물 수
- 식물별 카드: 관찰 횟수, 최근 물주기, 최근 키, 관리 필요 표시

## 6) MCP 확장 설명 화면 (`/mcp.html`)
- MCP 적용 목적
- 4개 Tool 명세 (getPlantLogs, analyzeGrowthTrend, suggestCarePlan, exportJournalData)
- `/api/mcp/tools` 메타정보 링크
- 과금/비용 설명
- 향후 확장 방향

## 디자인 가이드
- 컬러: 녹색 계열 (`--green-50 ~ --green-700`)
- 폰트: 시스템 폰트 (Noto Sans KR fallback)
- 카드형 레이아웃, 둥근 모서리 10px, 부드러운 그림자
- 반응형 그리드 (`auto-fill, minmax(...)`)
- 버튼/문구는 한글 우선
