# 01. 프로젝트 기획서

## 1) 서비스 개요
**AI 식물관찰일지**는 사용자가 일상에서 키우는 식물의 상태를 손쉽게 기록하고, AI가 관찰 요약문과 관리 조언을 자동으로 생성해 주는 웹 기반 관찰일지 서비스이다.

- 서비스명: AI 식물관찰일지
- 카테고리: 일상생활 / 라이프로그
- 형태: 웹 (반응형, PC + 모바일)
- 배포: Render 무료 플랜 + 무료 공개 URL
- 확장 아키텍처: MCP (Model Context Protocol)

## 2) 문제 정의
- 식물을 키우는 사람들은 잎/흙/물주기/햇빛을 기록할 통일된 양식이 없음
- 종이 메모는 검색·통계가 불가능, 일반 메모앱은 식물 관리 맥락이 없음
- 매일 사진과 상태를 적어도, 종합적인 “관리 조언”까지 자동으로 정리해 주는 도구는 드뭄

## 3) 해결 방식
1. 통일된 입력 폼(잎/흙/햇빛/물주기/키/사진/메모)으로 관찰을 빠르게 기록
2. 입력된 상태값을 바탕으로 **규칙 기반 AI 요약 + 관리 조언** 자동 생성 (무료)
3. API Key가 설정된 경우 동일 인터페이스로 **Anthropic Claude API** 호출 (선택)
4. 카드형 목록, 검색/필터, CSV/JSON 내보내기 제공
5. MCP 구조를 통해 향후 AI 에이전트와 데이터 연동이 가능하도록 설계

## 4) 핵심 가치
- **빠른 기록**: 1분 안에 한 건의 관찰을 끝낼 수 있는 UX
- **자동 정리**: 입력만 하면 요약과 조언까지 한 번에
- **확장성**: REST와 MCP가 동일한 도구 로직을 공유 → 추후 에이전트 통합 용이
- **0원 운영**: 무료 플랜 + 규칙 기반 기본값으로 비용 0

## 5) 대상 사용자
- 식물 초보자: 어떻게 관리할지 모르는 사람
- 식물 애호가: 여러 식물의 상태를 체계적으로 관리하고 싶은 사람
- 데이터 기록을 좋아하는 사람: CSV/JSON 으로 자신의 식물 관리 이력을 보관

## 6) 차별점
- **MCP 확장 구조**: 단순 웹앱이 아니라, AI 에이전트 시대를 고려한 표준 인터페이스 설계 사례 제시
- **AI 모드 자동 전환**: API Key 유무에 따라 규칙 기반↔실제 AI API 호출을 자동 선택
- **공유된 비즈니스 로직**: REST API 핸들러와 MCP Tool 이 같은 함수를 호출 → 중복 제거

## 7) 일정 / 마일스톤 (MVP)
| 단계 | 내용 |
| --- | --- |
| 기획 | 요구사항 정리, MCP Tool 명세 작성 |
| 백엔드 | Express + JSON 저장소, AI 모듈, MCP 도구 함수 |
| 프론트엔드 | 6개 화면, 녹색 테마, 반응형 |
| MCP | stdio JSON-RPC 샘플 서버 |
| 배포 | Render Web Service, 공개 URL 확보 |
| 제출 | Google Drive 폴더 구성, 시연영상 |
