# 04. 데이터 구조

## 저장 위치
`data/journal.json` (단일 JSON 파일)

> Render 무료 플랜의 디스크는 영구 보장이 아니므로, README 에 “데모 환경에서는 재시작 시 초기화될 수 있다”고 명시합니다.
> 사용자가 명시적으로 요청하기 전까지 이 저장 방식은 변경하지 않습니다 (변경 통제 원칙).

## 루트 스키마
```json
{
  "plants":   [ Plant, ... ],
  "journals": [ Journal, ... ]
}
```

## Plant 객체
| 필드 | 타입 | 비고 |
| --- | --- | --- |
| `id` | string | 자동 생성 (`plant_…`) |
| `name` | string | **필수**, 식물명 |
| `species` | string | 종류 (예: 허브, 다육) |
| `location` | string | 키우는 장소 |
| `startedAt` | string | `YYYY-MM-DD`, 키우기 시작일 |
| `memo` | string | 자유 메모 |
| `createdAt` | string | ISO 시각 |

## Journal 객체
| 필드 | 타입 | 비고 |
| --- | --- | --- |
| `id` | string | 자동 생성 (`jrn_…`) |
| `plantId` | string | Plant.id 참조 |
| `plantName` | string | 표시용 (Plant.name 캐싱) |
| `observedAt` | string | `YYYY-MM-DD` |
| `leafState` | string | "싱싱함" / "보통" / "시들음" / "변색" |
| `soilState` | string | "적당함" / "건조함" / "매우 건조함" / "너무 촉촉함" |
| `sunState` | string | "충분함" / "보통" / "부족함" |
| `watered` | boolean | 물주기 여부 |
| `growthCm` | number/null | 키 또는 성장 수치 |
| `photoUrl` | string | `/uploads/...` 경로 |
| `memo` | string | 자유 메모 |
| `aiSummary` | string | AI 관찰 요약 (생성 시 저장) |
| `aiAdvice` | string | AI 관리 조언 (생성 시 저장) |
| `createdAt` | string | ISO 시각 |
