# 03. 기능 목록

## MVP 필수 기능
| # | 기능 | 위치 | 비고 |
| --- | --- | --- | --- |
| F1 | 식물 등록 | `/plants.html` | 이름 필수 |
| F2 | 식물 수정/삭제 | `/plants.html` | 삭제 시 관련 일지도 함께 삭제 |
| F3 | 관찰일지 작성 | `/journal.html` | 잎/흙/햇빛/물/키/사진/메모 |
| F4 | 사진 업로드 | `/journal.html` | 5MB 제한, `public/uploads/` |
| F5 | AI 요약 생성 | `/api/ai/summary` | 규칙 기반(기본) / Gemini API(선택) |
| F6 | AI 관리 조언 생성 | `/api/ai/advice` | 동일 모드 자동 전환 |
| F7 | 관찰일지 목록 (카드) | `/list.html` | 필터/정렬 지원 |
| F8 | 관찰일지 수정/삭제 | `/list.html` | 모달 수정 |
| F9 | 검색/필터 | `/list.html` | 식물명, 기간, 키워드 |
| F10 | CSV/JSON 내보내기 | `/api/export` | MCP `exportJournalData`와 동일 |
| F11 | 통계 / 요약 | `/stats.html` | 관리 필요 식물 자동 표시 |
| F12 | MCP Tool 메타 노출 | `/api/mcp/tools` | 4종 Tool 명세 |
| F13 | MCP stdio 서버 샘플 | `mcp-server/server.js` | JSON-RPC |

## 향후 확장 가능 기능
- 사용자 인증 / 다중 사용자 지원
- 외부 식물 정보 API 연동 (학명, 적정 일조량 등)
- Google Calendar 연동 물주기 알림
- 이미지 기반 잎 상태 자동 분류
- PWA / 모바일 홈 화면 추가
