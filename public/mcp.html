MCP 기반 확장 구조

본 서비스는 MCP (Model Context Protocol) 기반 확장 구조를 고려하여 설계되었습니다. AI가 관찰일지 데이터, 외부 식물 정보 API, 캘린더 알림 등과 표준화된 방식으로 연결될 수 있도록 핵심 비즈니스 로직(lib/tools.js)을 REST API와 MCP 서버가 공유합니다.

MCP Tool 설계

  • getPlantLogs - 특정 식물의 관찰일지 목록을 조회
    입력: plantName, plantId, from, to / 출력: 관찰일지 배열
    예시: "내 바질 최근 기록 보여줘."
  • analyzeGrowthTrend - 키/잎/물주기 기록을 기반으로 성장 추이 분석
    입력: plantName / 출력: 키 변화량, 물주기 횟수, 요약
    예시: "내 바질 성장 상태 어때?"
  • suggestCarePlan - 최근 상태 기반 관리 조언 생성
    입력: plantName, leafState, soilState, sunState, watered, memo / 출력: 관리 등급, 조언
    예시: "오늘 몬스테라 상태 보고 어떻게 관리할지 알려줘."
  • exportJournalData - 관찰일지 데이터를 CSV/JSON으로 내보내기
    입력: format, plantName, from, to / 출력: 파일
    예시: "내 식물관찰일지 CSV로 내보내줘."

실제 MCP Tool 메타정보는 /api/mcp/tools 에서 JSON 으로 확인할 수 있습니다.

과금 / 비용

  • MCP 자체는 과금되는 서비스가 아니라 표준 프로토콜입니다.
  • 실제 비용은 AI API 호출, 서버, 저장소 사용량에서 발생합니다.
  • 본 MVP 는 Render 무료 플랜 + 규칙 기반 요약 조합으로 운영 비용 0원입니다.
  • AI API Key를 환경변수에 넣으면 자동으로 Google Gemini API 호출로 전환됩니다.

향후 확장 방향

  • 외부 식물 정보 API 연동 (학명, 적정 일조량, 적정 습도 등)
  • Google Calendar 연동을 통한 물주기 자동 알림
  • 이미지 기반 잎/병해충 자동 분류 모델 연결
  • 다중 사용자/로그인 지원
